# Advanced Memory Forensics SIEM Dashboard

## Overview

A Python-based Security Information and Event Management (SIEM) dashboard for Linux memory forensics.

### Features

* Live Memory Acquisition using LiME
* Strings Extraction
* Volatility 3 Analysis
* Threat Detection Engine
* High / Medium / Low Threat Classification
* Automated Mitigation
* Real-Time Monitoring
* Threat Visualization Graphs

## Technologies Used

* Python
* Tkinter
* LiME
* Volatility 3
* Linux
* Matplotlib

## Project Workflow

1. Acquire memory using LiME
2. Extract strings from memory dump
3. Run Volatility plugins
4. Correlate findings using SIEM rules
5. Classify threats
6. Display results in GUI
7. Apply mitigation actions

## Usage

```bash
sudo python3 dashboard.py
```
